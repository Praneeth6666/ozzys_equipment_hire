USE YOUR ORIGINAL HIGH-QUALITY TRAILER PHOTO
============================================

The hero image is currently 768×1024 pixels, so it looks soft on screen.

To get ORIGINAL quality:

1. Get the full-resolution photo from your phone or camera
   (e.g. 3024×4032 or 4032×3024 – not a compressed or resized copy).

2. Replace this file with your photo:
   → public/trailer.png

   Option A: Replace the file
   - Rename your photo to trailer.png
   - Put it in the "public" folder, overwriting the existing trailer.png

   Option B: If your photo is a JPG
   - Save it as public/trailer.jpg (in the "public" folder)
   - Tell your developer so the website can be updated to use trailer.jpg

3. The site will then show your image at full quality (it never scales the image up).

No code changes are needed if you replace public/trailer.png with a PNG or JPG of the same name. If you use trailer.jpg instead, the site code needs one small update to use that filename.
